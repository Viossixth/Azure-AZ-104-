**Task 1: Deploy an Azure Container Instance using a Docker image**

In the first step of this lab, I had to create a container instance using a docker image. A container instance is a packaging environment where the code and dependencies of an application are stored and can be ran from.
It's an efficient way for packaging and running apps. A docker image is the actual blueprint or files of the app whilst the container instance is the live running app.
