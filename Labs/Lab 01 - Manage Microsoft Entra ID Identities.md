The purpose of this lab is to get hands on experience with Microsoft Entra ID Identities and use it to achieve a business solution. Users and user groups need to be created for Administrators who will be in charge of a new lab environment for pre-production testing of apps and services.
The engineers in charge of the new lab environment are new hires and will need new identities and permissions. The solutions is to create a users and a group to which they will belong to. They will have permissions as determined by their group they belong to.

**Job skills**
- Task 1: Create and configure user accounts.
- Task 2: Create groups and add members.

**Task 1**

To complete task 1, I created a user on Microsoft Entra. Under the Users tab, i selected New User and Create new user. I filled out the properties which were relevant and selected create user.
After successful creation i then invited a user from the same User's tab. Similar to the previous user, i filled out the relevant users and invited the user.
